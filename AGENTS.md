\## Code Navigation (jCodeMunch)

This project is indexed with jCodeMunch. Always use jCodeMunch MCP tools to explore code:

\- Use `search\_symbols` or `get\_symbol\_source` to locate and retrieve specific functions/classes by name instead of reading full files.

\- Use `get\_file\_outline` or `get\_repo\_outline` to inspect module and directory structure.

\- Use `get\_blast\_radius` before renaming or refactoring code to check downstream impact.
